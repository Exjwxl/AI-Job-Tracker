# AI Job Tracker

An AI-powered full-stack job application management platform that helps users organize job applications, analyze resumes using AI, track interviews, and improve resume quality with ATS-based feedback.

---

## Features

- AI Resume Analyzer
- ATS Score Generation
- Resume vs Job Description Matching
- Missing Keyword Detection
- AI Resume Suggestions
- Job Application Tracker
- Interview Scheduler
- Dashboard Analytics
- Secure PDF Upload
- REST API Backend
